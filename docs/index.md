# Naviox Vue documentation

Naviox adds search, command workflows and rich navigation to Vue 3 projects. Start with the component that matches the task, then customize its appearance without changing the core behavior.

- [Getting started](getting-started.md) — install and render your first palette
- [Composable inline commands](composable-command.md) — build your own command UI
- [Components](navigation.md) — command palette, mega-menu and autocomplete
- [Themes and customization](customization.md) — built-ins, named themes, slots/render callbacks
- [Public API](public-api.md) — exports, ownership, and shared controllers
- [Accessibility](accessibility.md) — keyboard behavior and testing considerations
- [Compatibility](compatibility.md) — supported versions and SSR notes
- [Publishing](publishing.md) — contributing and release steps

The underlying engine is [`@blcklab/naviox`](https://www.npmjs.com/package/@blcklab/naviox). No other framework package is required.
