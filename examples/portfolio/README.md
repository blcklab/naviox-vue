# Portfolio showcase

This is a **separate example app**, not a second package. It demonstrates `NavioxPalette`, slots, nested commands, async actions, and all three themes. After installing dependencies, run `npm run demo` from the repository root. The Vite dev server serves this standalone Vue example without including it in the npm package.

The example uses CSS illustrations rather than AI-generated or copyrighted anime artwork. The visuals take inspiration from quiet night scenes, paper stationery, and cinematic color grading.
